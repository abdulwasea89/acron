# Data Model

## Organizations
- `org_id` (UUID, primary key)
- `org_code` (String, 8-12 alphanumeric, unique)
- `name` (String)
- `email` (String, unique)
- `stripe_customer_id` (String, nullable)
- `stripe_connect_account_id` (String, nullable)
- `saas_tier` (Enum: starter/pro/enterprise, default: starter)
- `saas_status` (Enum: active/grace/suspended/cancelled, default: active)
- `mfa_required` (Boolean, default: false)
- `enrollment_mode` (Enum: open/invite_only, default: open)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Users
- `id` (UUID, primary key)
- `email` (String, unique)
- `password_hash` (String)
- `full_name` (String, nullable)
- `is_active` (Boolean, default: true)
- `mfa_enabled` (Boolean, default: false)
- `mfa_secret` (String, nullable)
- `hibp_checked_at` (Timestamp, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Organization Members
- `id` (UUID, primary key)
- `organization_id` (UUID, foreign key → organizations.org_id)
- `user_id` (UUID, foreign key → users.id)
- `role` (Enum: owner/manager/trainer/front_desk/member)
- `status` (Enum: active/grace/expired/frozen/cancelled/banned, default: active)
- `joined_at` (Timestamp)
- `left_at` (Timestamp, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Membership Plans
- `id` (UUID, primary key)
- `organization_id` (UUID, foreign key → organizations.org_id)
- `name` (String)
- `price` (Decimal)
- `billing_type` (Enum: recurring/one_time_pack/drop_in)
- `billing_interval` (Enum: month/quarter/year, nullable)
- `inclusions` (JSON, default: [])
- `rules` (JSON, default: [])
- `visibility` (Enum: public/members_only/invite_only, default: public)
- `status` (Enum: draft/paused/archived, default: draft)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Subscriptions
- `id` (UUID, primary key)
- `organization_member_id` (UUID, foreign key → organization_members.id)
- `plan_id` (UUID, foreign key → membership_plans.id)
- `stripe_subscription_id` (String, nullable)
- `stripe_payment_intent_id` (String, nullable)
- `status` (Enum: active/grace/expired/cancelled, default: active)
- `amount` (Decimal)
- `currency` (String, default: usd)
- `current_period_start` (Timestamp)
- `current_period_end` (Timestamp)
- `trial_end` (Timestamp, nullable)
- `canceled_at` (Timestamp, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Payments
- `id` (UUID, primary key)
- `organization_member_id` (UUID, foreign key → organization_members.id)
- `amount` (Decimal)
- `currency` (String, default: usd)
- `method` (Enum: card/cash/bank_transfer/mobile_wallet)
- `stripe_payment_intent_id` (String, nullable)
- `stripe_charge_id` (String, nullable)
- `receipt_image_url` (String, nullable)
- `ai_status` (Enum: pending/reviewed/auto_approved/rejected, default: pending)
- `ai_confidence` (Integer, 0-100, nullable)
- `idempotency_key` (String, nullable, unique)
- `status` (Enum: completed/failed/refunded, default: completed)
- `logged_by` (UUID, foreign key → users.id, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Receipt Uploads
- `id` (UUID, primary key)
- `payment_id` (UUID, foreign key → payments.id)
- `original_image_url` (String)
- `processed_image_url` (String)
- `ocr_raw_text` (Text, nullable)
- `extracted_amount` (Decimal, nullable)
- `extracted_date` (Date, nullable)
- `extracted_payer_name` (String, nullable)
- `extracted_payee_name` (String, nullable)
- `authenticity_score` (Integer, 0-100, nullable)
- `duplicate_hash` (String, nullable)
- `cross_validation_passed` (Boolean, default: false)
- `confidence_score` (Integer, 0-100, nullable)
- `auto_approved` (Boolean, default: false)
- `admin_notes` (Text, nullable)
- `admin_action` (Enum: none/approved/rejected/requested_info, default: none)
- `admin_at` (Timestamp, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Payroll Runs
- `id` (UUID, primary key)
- `organization_id` (UUID, foreign key → organizations.org_id)
- `pay_period_start` (Timestamp)
- `pay_period_end` (Timestamp)
- `status` (Enum: draft/locked/finalized/paid, default: draft)
- `total_gross` (Decimal, default: 0)
- `total_deductions` (Decimal, default: 0)
- `total_net` (Decimal, default: 0)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Payroll Entries
- `id` (UUID, primary key)
- `payroll_run_id` (UUID, foreign key → payroll_runs.id)
- `organization_member_id` (UUID, foreign key → organization_members.id)
- `fixed_salary` (Decimal, default: 0)
- `hourly_rate` (Decimal, default: 0)
- `hours_worked` (Decimal, default: 0)
- `per_class_rate` (Decimal, default: 0)
- `classes_taught` (Integer, default: 0)
- `commission_rate` (Decimal, default: 0)
- `commission_base` (Decimal, default: 0)
- `bonuses` (Decimal, default: 0)
- `deductions` (Decimal, default: 0)
- `advance_repayment` (Decimal, default: 0)
- `net_pay` (Decimal, default: 0)
- `payment_method` (Enum: bank_transfer/cash/mobile_wallet)
- `pay_stub_url` (String, nullable)
- `notes` (Text, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Cash Reconciliations
- `id` (UUID, primary key)
- `organization_id` (UUID, foreign key → organizations.org_id)
- `performed_by` (UUID, foreign key → users.id)
- `system_total` (Decimal, default: 0)
- `actual_count` (Decimal, default: 0)
- `discrepancy` (Decimal, default: 0)
- `discrepancy_notes` (Text, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)

## Audit Logs
- `id` (UUID, primary key)
- `organization_id` (UUID, foreign key → organizations.org_id, nullable)
- `user_id` (UUID, foreign key → users.id, nullable)
- `action` (String)
- `entity_type` (String)
- `entity_id` (UUID, nullable)
- `old_value` (Text, nullable)
- `new_value` (Text, nullable)
- `ip_address` (String, nullable)
- `user_agent` (String, nullable)
- `created_at` (Timestamp)

## Sessions
- `id` (UUID, primary key)
- `user_id` (UUID, foreign key → users.id)
- `organization_id` (UUID, foreign key → organizations.org_id)
- `token_hash` (String)
- `device_info` (String, nullable)
- `ip_address` (String, nullable)
- `expires_at` (Timestamp)
- `last_activity_at` (Timestamp)
- `revoked` (Boolean, default: false)
- `created_at` (Timestamp)

## Idempotency Keys
- `id` (UUID, primary key)
- `key` (String, unique)
- `request_hash` (String, nullable)
- `status` (Enum: in_progress/completed/failed, default: in_progress)
- `response_body` (Text, nullable)
- `completed_at` (Timestamp, nullable)
- `created_at` (Timestamp)
- `updated_at` (Timestamp)
